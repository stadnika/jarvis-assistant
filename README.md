# Модулі Jarvis

Запускай Jarvis з кореневої папки проєкту командою `python jarvis.py` або наявним файлом `запуск`.

Для керування медіасеансом браузера встанови залежність із кореневої папки проєкту:
`.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
YouTube Music має бути відкритий у браузері й мати активний медіасеанс.

Озвучення через `pyttsx3` і локальні команди працюють без інтернету. Розпізнавання голосу за замовчуванням також офлайн через Vosk. Для української моделі `uk_v3_dynamic_nano` її папка моделі має бути в `models\uk_v3_dynamic_nano\model`; це шлях, заданий у `VOSK_MODEL_PATH` у `config.py`. Після встановлення моделі інтернет для розпізнавання не потрібен. Для онлайн-розпізнавання можна змінити `ASR_BACKEND` на `"google"`. Погода, відкриття вебсайтів та інші мережеві дії залишаються залежними від інтернету.

- `config.py` — голосові псевдоніми, команди, назви програм, адреси сайтів і налаштування погоди.
- `command_parsing.py` — нормалізація тексту, точне зіставлення команд і розбір голосових команд. Варіанти вимови команд задаються в `config.py`.
- `voice.py` — озвучення відповідей, обробка мікрофона й розпізнавання мовлення.
- `command_execution.py` — виконання звичайних і динамічних команд.
- `system_actions.py` — керування програмами й вікнами Windows, звуком, скриншотами та отримання погоди.
- `state.py` — спільний стан прослуховування, час завершення таймера та черга команд.
- `main.py` — налаштування мікрофона й головний цикл обробки команд і таймера.
- `jarvis.py` — файл запуску, який викликає `jarvis_modules.main`.
